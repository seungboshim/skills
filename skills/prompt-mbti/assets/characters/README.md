# 유형 캐릭터

파일 이름은 유형 코드 그대로다. `LDTW.png` 처럼 대문자 네 글자에 `.png`.
`render.sh` 가 카드를 만들 때 여기서 찾아 넣는다. 없으면 그 자리를 비우고 카드는 그대로 나온다.

찾는 순서는 이렇다.

1. `~/.claude/prompt-mbti/characters/<코드>.png` — 사용자가 직접 갈아 끼운 그림
2. `assets/characters/<코드>.png` — 저장소에 든 기본 그림

**크기를 지킨다.** 배포 ZIP 이 3MB 를 넘으면 안 되므로 장당 150KB 이하로 맞춘다.
256x256 이면 충분하다. 16장을 다 넣어도 2MB 안쪽이어야 한다.
