# Handoff

컨텍스트가 꽉 차기 전에 대화를 문서 하나로 접고, 비운 세션에서 그 문서로 이어간다.
자동 요약은 형식도 분량도 통제할 수 없다. 이 문서는 네가 정한 형식으로 남는다.

## 언제 돌아가나

- **자동**: Stop 훅이 컨텍스트 80%를 감지하면 문서를 쓰라고 지시한다. 그 뒤로도 85·90·95%를
  넘길 때마다 다시 지시하니, `/clear` 를 미뤄도 문서가 낡지 않는다.
- **수동**: `/handoff` 를 부르면 지금 상태로 바로 쓴다. `/clear` 를 누르기 직전에 이걸 쓰면
  문서가 가장 정확하다.

두 경로 모두 아래 형식을 따른다.

## 어디에 쓰나

`.claude/handoff.md` (프로젝트 루트 기준). 이미 있으면 덮어쓴다. 여러 개를 쌓지 않는다.

`/clear` 하면 SessionStart 훅이 이 파일을 새 세션에 넣고 `.claude/handoff.md.done` 으로
밀어둔다. compact 이 돌 때도 넣지만, 같은 세션이 이어지므로 파일은 그대로 남긴다.

주입은 화면에 보이지 않으므로, 훅이 `systemMessage` 로 무엇을 이어받았는지 한 줄 알린다.
문서의 첫 제목을 그대로 보여주니 `# 핸드오프: <한 줄>` 의 한 줄이 곧 알림 문구가 된다.

## 무엇을 담나

```markdown
# 핸드오프: <지금 하는 일 한 줄>

## 다음 한 걸음
<새 세션이 읽고 바로 시작할 수 있는 행동 하나. 파일 경로와 함수 이름까지 적는다>

## 끝난 것
- <검증까지 끝난 것만. 무엇으로 확인했는지 함께 적는다>

## 남은 것
- <순서가 있으면 순서대로>

## 알아둘 것
- 결정: <무엇을 골랐고 왜 골랐나. 버린 안도 한 줄로 남긴다>
- 헛다리: <시도했다 실패한 길. 새 세션이 같은 길을 또 파지 않게>
- 만진 파일: `path/to/file.ts:120` 처럼 줄까지
```

빈 섹션은 지운다. 남길 게 없으면 그 항목을 통째로 빼라.

## 담지 않는 것

- 코드 전문. 파일 경로와 줄 번호로 충분하다. 새 세션이 직접 열어 읽는다
- 대화 재현. 누가 뭘 물었는지는 필요 없다. 결론과 이유만 남긴다
- 내부 작업 용어. `[충돌 A]`, `AC7` 같은 표시는 다음 세션에서 해독이 안 된다
- 추측을 사실처럼. 확인한 것과 확인 안 한 것을 갈라 적고, 검증하지 않았으면 "미확인"이라고 쓴다

## 쓰고 나서

문서 경로와 함께 `/clear` 를 사용자에게 안내하고 답을 마친다. `/clear` 는 사람이 누른다.
훅은 슬래시 명령을 실행할 수 없다.

## 설정

- 임계값과 갱신 간격: `hooks/handoff.py` 의 `THRESHOLD`, `REWRITE_STEP`
- 자동 요약을 끄고 핸드오프에만 맡기려면 settings.json 에 `"autoCompactEnabled": false`
- 판정 로직 점검: `python3 hooks/handoff.py selftest`

**컨텍스트 한계는 모델 이름으로 가른다.** 요즘 모델은 대부분 1M 이라 (Fable 5, Mythos 5,
Opus 5, Opus 4.6~4.8, Sonnet 5, Sonnet 4.6) 그쪽을 기본으로 잡고, Haiku 와 4.5 세대
이하만 200k 로 본다. 목록은 `hooks/handoff.py` 의 `NARROW_MARKERS` 다. 이름을 못 읽으면
넓게 보고, 관측 크기가 이미 200k 를 넘었으면 이름이 무엇이든 1M 으로 판단한다.

직접 못박으려면 settings.json 의 `env` 에 넣어라. env 가 가장 세다.

```json
{ "env": { "HANDOFF_CONTEXT_LIMIT": "1000000" } }
```

`.claude/handoff.md` 와 `.claude/handoff.tok` 은 세션마다 바뀌니 `.gitignore` 에 넣어라.
