# 프롬프트 MBTI — 성격 검사는 묻고, 이 스킬은 센다

## 한 줄 소개

질문지 없이, 내가 에이전트에게 이미 한 말을 세어 프롬프트 습관을 16유형과 실제 숫자로 보여주는 스킬.

## 제출 설명 본문

성격 검사는 “나는 계획적인 편인가?”를 묻습니다. 프롬프트 MBTI는 묻지 않습니다.
`~/.claude/projects`에 이미 쌓인 행동 로그에서 **사람이 직접 타이핑한 지시만** 골라 셉니다.

지시 길이, 새벽 작업 비중, 확인·검증 요청 비중, 저장소 편중도로 네 축을 만들고 16유형 중
하나를 냅니다. 평균 대신 중앙값을 써서 긴 에러 로그 한 번에 결과가 흔들리지 않게 했고,
2000자가 넘는 붙여넣기는 길이 판정에서 뺍니다. 임계값에서 3포인트 안쪽이면 억지로 한쪽에
밀지 않고 경계형이라고 밝힙니다.

실제 제 기록 1,769건·76세션·29개 저장소를 6.5초에 분석한 결과는 `LDTW · 총괄 기획자`였습니다.
말버릇 1위는 `다시` 237회, `ㄱㄱ`는 72회였습니다. 긴 설명을 쓰는 사람이 승인은 두 글자로
한다는 사실은 질문지로는 나오지 않습니다.

결과는 유형 카드, 근거 숫자 네 개, 눈에 띄는 습관, 처방 하나로 끝납니다. 매달 다시 돌리면
지난 결과와 비교해 **바뀐 축만** 알려줍니다. 팀원도 같은 계산식으로 각자 돌릴 수 있습니다.

원문 지시는 한 줄도 출력하지 않고 네트워크도 쓰지 않습니다. 기록이 없으면 멈추고, 100건
미만이면 임시 결과라는 표본 주의를 붙입니다. 공유 전에는 말버릇과 저장소 이름에 사내 용어나
고객명이 있는지 확인하고, 사용자의 승인 없이는 외부로 발행하지 않습니다.

## 심사 기준별 근거

- **기상천외함:** 프롬프트 기록을 “무엇을 만들었나”가 아니라 “어떻게 시켰나”의 행동 로그로 뒤집었다.
- **유용함:** 매달 한 번 습관 변화를 측정하고 반복 설명을 프로젝트 문서로 내릴 근거를 준다.
- **완성도:** 수집 → 정량 판정 → 유형 해석 → 저장 → 이전 결과 비교가 한 흐름으로 이어진다.
- **재사용성:** 프로젝트 구조와 무관하고 같은 임계값으로 다른 Claude Code 사용자도 실행한다.
- **신뢰성:** 원문 비출력, 로컬 처리, 작은 표본 경고, 잘못된 기간 입력 거부, 12개 회귀 단정.
