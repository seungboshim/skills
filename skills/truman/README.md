# truman

**나도 몰랐던 내 하루를 누군가 방송하고 있었다.**

오늘 하루 개발한 흔적을 모아 3인칭 관찰 예능 내레이션 에피소드로 만드는 Claude Code 스킬입니다.
시즌과 회차가 누적되고, 못 끝낸 일은 다음 회 예고가 됩니다.

## 흔한 방식과 무엇이 다른가

하루를 되짚는 흔한 방식은 회고입니다. 사람이 기억을 더듬어 "오늘 뭐 했지"를 적습니다.
문제는 기억이 이미 편집된 뒤라는 겁니다. 잘 풀린 일은 남고, 두 시간 헤맨 구간은 사라집니다.

truman 은 기억을 묻지 않습니다. **이미 기계가 적어둔 기록만 읽습니다.**

- `git log` 와 `git reflog`: 무엇을 만들었고 무엇을 되돌렸는지
- Claude Code 세션 기록: 몇 시에 어디서 무슨 말을 했는지
- 셸 히스토리와 워킹 트리 상태: 무엇을 반복했고 무엇을 안 끝냈는지

그리고 그 기록을 회고 문서가 아니라 **방송 대본으로 편집합니다.** 형식을 바꾼 이유가 있습니다.
회고는 잘한 것을 적게 되고, 관찰 예능은 이상한 것을 먼저 비춥니다. 오후 6시 31분에 커밋 하나를
지운 사실은 회고에 안 적히지만 콜드오픈으로는 최고의 장면입니다.

읽히지 않는 회고를 한 편 더 만드는 대신, **끝까지 읽히는 형식에 회고를 숨겨 넣었습니다.**
에피소드 마지막 두 블록이 그 회고입니다.

## 어떻게 쓰나

### 입력

없습니다. `/truman` 이라고 치거나 "오늘 방송 만들어줘"라고 말하면 됩니다.
사람이 채워 넣을 항목이 하나도 없습니다.

### 처리

1. `scripts/collect.sh` 가 로컬 기록을 훑어 자료를 한 파일로 모읍니다. 읽기 전용이고 네트워크를 쓰지 않습니다
2. `~/.claude/truman/state.json` 에서 지난 회차와 지난 예고를 읽습니다
3. 모아온 자료에 있는 사실만으로 대본을 씁니다
4. 에피소드를 `~/.claude/truman/episodes/S01E04.md` 로 저장하고 상태를 갱신합니다

### 결과

이런 한 편이 나옵니다. 아래는 실제 실행 결과에서 저장소 이름과 커밋 메시지를 빼고 옮긴 것입니다.

```
S02E05 — 「그는 왜 같은 문서를 열 번 열었나」
방송일 2026-08-14 · 발언 72건 · 커밋 28건

오후 6시 31분. 그는 방금 만든 커밋을 지웁니다.
reset: moving to HEAD~1. 설명은 없습니다.
시청자 여러분, 이 장면을 기억해 두시기 바랍니다.

  (중략)

오후 2시 24분, 그는 이렇게 말합니다.
> "ㄱㄱ 해줘. 방금함"
무엇을 방금 했는지는 기록에 없습니다.

제작진 노트
- docs/backlog.md 10회 수정. 같은 구간에 코드 파일 최다 수정은 2회였습니다.
  오늘의 병목은 구현이 아니라 결정이었습니다
- 되돌리기 3회(reset 1, amend 2). 셋 다 오후 2시 이후에 몰렸습니다
- 20시 27분부터 6시간 33분의 공백. 쉬었는지 막혔는지는 기록에 없습니다

차회 예고
- 커밋 안 한 변경 11개가 그대로 남아 있습니다
- 7월 27일에 넣어둔 stash 하나. 오늘로 19일째입니다
- 다음 회, 「롤백」
```

**제작진 노트와 차회 예고가 이 스킬의 본체입니다.** 웃기려고 만들었지만 이 두 블록은
관찰된 신호만 적습니다. 인격 평가와 총평은 규칙으로 금지했습니다.

## 언제 반복해서 쓰나

하루를 닫을 때마다 씁니다. 자료가 매일 새로 쌓이므로 매번 다른 에피소드가 나옵니다.

반복해서 쓸수록 세지는 부분이 있습니다. **회차가 누적되면 떡밥이 살아납니다.**
지난 회차의 차회 예고를 오늘 자료와 대조해서, 같은 항목이 또 남아 있으면 "3화 연속 등장"으로
적습니다. 3주 방치된 stash 는 회고에서는 매번 새 항목이지만 여기서는 시즌을 관통하는 떡밥이
됩니다. 미루는 일이 미룰수록 더 크게 보이는 구조입니다.

## 다른 상황에도 쓸 수 있나

- 구간을 바꿉니다. `--day 2026-08-14` 로 특정 방송일, `--hours 6` 으로 짧은 구간
- 저장소 경로를 바꿉니다. `--root ~/work` 로 다른 작업 폴더
- 톤을 바꿉니다. 관찰 예능이 기본이고 자연 다큐, 느와르, 스포츠 중계를 고를 수 있습니다.
  고른 톤은 상태 파일에 남아 다음 회차에도 이어집니다
- 등장인물 호칭을 바꿉니다. 기본은 "그"입니다

Claude Code 를 쓰고 git 을 쓰는 사람이면 설정 없이 그대로 돌아갑니다. 특정 프로젝트 구조를
전제하지 않습니다.

## 실패할 때와 안 하는 것

- **자료가 비어 있으면 대본을 쓰지 않습니다.** 커밋도 발언도 없으면 그렇게 말하고 멈춥니다.
  없는 장면을 지어내면 이 스킬은 소설이 되기 때문입니다
- `jq` 가 없으면 어록 구간을 건너뛰고 설치 방법을 알려줍니다. 나머지 구간은 그대로 나옵니다
- 셸 히스토리가 구간보다 오래됐으면 **마지막 기록 시각을 알려주고 건너뜁니다.** IDE 안에서
  터미널을 쓰면 히스토리 파일에 안 쌓이는데, 이걸 모르고 "터미널을 안 썼다"고 쓰면 거짓말이
  됩니다
- 자료에 없는 사실은 쓰지 않습니다. 심리 묘사는 관찰된 행동에서만 추론하고 추론임이 드러나게
  씁니다. "그는 지쳤다"가 아니라 "그는 같은 명령을 세 번 반복했다"로 씁니다

## 개인정보와 외부 행동

- 수집기는 **로컬 파일만** 읽습니다. 네트워크를 쓰지 않고 아무것도 고치지 않습니다
- 세션 기록에서 뽑는 발언은 **사용자가 직접 타이핑한 것**만입니다. 도구 결과나 파일 내용은
  읽지 않습니다
- 그래도 어록에 비밀이 섞일 수 있습니다. 에피소드를 밖으로 발행하기 전에 어록을 다시 훑고,
  자격 증명이나 고객명이 있으면 **사용자에게 알리고 뺍니다**
- 사내 저장소가 섞여 있으면 발행할 때 저장소 이름을 가릴지 물어봅니다
- 발행은 사용자가 요청할 때만 합니다. 저장은 전부 `~/.claude/truman/` 아래 로컬입니다

## 작동 근거

- 수집기에 자기 점검이 붙어 있습니다. `bash scripts/test-collect.sh` 를 돌리면 임시 저장소를
  만들어 커밋·되돌리기·미완성 변경을 심고, 그게 자료에 그대로 잡히는지 **단정 9개**로 확인합니다
- 저장소 47개와 세션 기록 1000여 개를 훑는 데 몇 초가 걸립니다. 실측한 값입니다
- 설치된 위치에서 다른 디렉터리를 작업 폴더로 두고 실행해도 동작하는 것을 확인했습니다

## 설치

```bash
/plugin marketplace add seungboshim/skills
/plugin install truman@seungboshim-skills
```

`jq` 가 있으면 어록 구간까지 살아납니다. 없어도 나머지는 동작합니다.
