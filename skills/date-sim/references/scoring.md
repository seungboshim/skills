# 호감도 규칙과 부검 리포트 포맷

## 호감도 기본값

시작 호감도는 30, 범위는 0~100이다. 한 턴에 하나의 델타만 매긴다. 아래 표를
기준으로 삼고, 세팅에서 정한 난이도 배수를 곱한다. 배수는 음수 델타에만 곱한다.
편안함은 감점을 봐주는 난이도지 가점까지 후하게 주는 난이도가 아니다.

| 사용자 반응 | 델타 | 비고 |
|---|---|---|
| 상대 말을 구체적으로 되묻거나, 상대 감정에 이름을 붙여 공감함 | +2 ~ +5 | 화제를 넓혔을 때만 |
| 대답은 하지만 안 묻고 안 넓힘 ("네", "그렇네요", "오 그래요") | 0 ~ -1 | 아무 말도 안 한 것과 다르지 않다 |
| 한 단어·성의 없는 대답이 반복됨 | -3 ~ -5 | |
| 지뢰를 밟음 (그 상대의 지뢰 항목 참고) | -5 ~ -10 | |
| 상대가 흘린 불편 신호(말끝 흐리기, 화제 돌리기, 텐션 낮아짐)를 못 보고 밀어붙임 | -8 ~ -15 | 공감 실패라 가장 크게 뺀다 |
| 우연히라도 상대의 숨은 니즈에 맞는 반응을 함 | +2 ~ +3 보너스 | 위 델타에 더한다 |

난이도 배수: 편안함 ×0.7, 보통 ×1.0, 까다로움 ×1.3. (예: 보통에서 -8인 지뢰가
까다로움에서는 -10.4, 반올림해서 -10)

## 게이지 표시

`filled = round(호감도 / 100 * 8)` 칸을 `▓`, 나머지 `8 - filled` 칸을 `░`로
채우고 뒤에 숫자를 붙인다. 예: 호감도 33 → `▓▓▓░░░░░ 33`.

한 칸은 12.5점이다. 칸 수를 눈대중으로 늘리지 않는다. 호감도가 올랐는데 칸이
그대로인 턴이 정상이다. 28 과 36 은 둘 다 3칸이 아니라 각각 2칸과 3칸이다.

## 종료와 등급

| 조건 | 결과 |
|---|---|
| 진행 중 호감도 0 이하 | 조기 종료. 상대가 자연스럽게 자리를 정리하고 뜬다 |
| 마지막 턴, 최종 호감도 80 이상 | 애프터 성공 (상대가 먼저 다음 약속을 제안) |
| 마지막 턴, 50~79 | 무난한 헤어짐 (인사는 하지만 애프터는 불확실) |
| 마지막 턴, 20~49 | 어색한 헤어짐 (상대가 대화를 서둘러 정리함) |
| 마지막 턴, 1~19 | 식은 헤어짐 (상대가 사무적으로 인사만 하고 감) |

## 태그 어휘 (고정)

history.jsonl 의 `tags` 와 리포트의 "고질병" 판정에는 아래 태그만 쓴다. 새 표현을
그때그때 만들지 않는다.

`질문_부족` `리액션_부족` `자기얘기_과다` `지뢰_밟음` `불편신호_무시` `단답_반복`
`니즈_못알아챔`

같은 태그가 최근 3회 이상(이번 회차 포함) 나오면 리포트에 "고질병"으로 표시한다.

## 부검 리포트를 만드는 절차

1. **세션 로그를 처음부터 다시 훑는다.** 사용자가 실제로 친 문장만 센다. 턴
   전체를 어림잡지 않는다.
2. 사용자의 각 발화를 문장 단위로 쪼개 셋 중 하나로 분류한다.
   - **자기중심 문장**: 자기 얘기·경험·자랑을 말한 문장
   - **질문**: 물음표나 의문형 어미로 상대에게 되물은 문장
   - **리액션**: 맞장구·공감 표현 ("오", "진짜요?", "그랬구나", "대박" 등)
3. `자기 얘기 비율 = 자기중심 문장 수 / 전체 문장 수 × 100`
4. `질문 횟수`, `리액션 횟수`는 각각의 총합이다.
5. 호감도 델타의 절대값이 큰 턴 상위 3개를 결정적 순간으로 뽑는다. 부정 델타를
   최소 1~2개는 반드시 포함한다. 배울 게 없는 리포트는 리포트가 아니다.
6. 상대의 숨은 니즈가 신호로 드러난 턴들을 찾아, 사용자가 그중 하나라도 니즈에
   맞게 반응했으면 "알아챔", 하나도 못 맞혔으면 "못 알아챔"으로 판정한다.
7. 가장 심각한 지표 하나를 골라 다음 훈련 과제로 낸다. 두 개 이상 주지 않는다.
8. `~/.claude/date-sim/history.jsonl` 을 읽어 최근 회차와 질문 횟수·리액션
   횟수를 비교하고, 태그 반복을 확인해 고질병 여부를 붙인다.
9. 이번 회차를 한 줄 JSON 으로 append 한다.

## 리포트 포맷

```md
## 부검 리포트

- 자기 얘기 비율: NN% (전체 N문장 중 N문장)
- 질문 횟수: N회
- 리액션 횟수: N회

### 결정적 순간

1. N턴: "인용" → 왜 갈림길이었는지 한 줄. 대신: "대안 대사"
2. N턴: "인용" → ...
3. N턴: "인용" → ...

### 숨은 니즈

상대의 숨은 니즈는 **<니즈>**였다. <알아챘다 / 못 알아챘다>. <근거 한 줄>

### 다음 훈련 과제

<하나만>

### 지난 회차와 비교

<있으면 비교, 없으면 이 섹션 자체를 뺀다>
```

## 실제 예시 (처음부터 끝)

세팅: 보통 / 카페 / 랜덤 → personas.md 시드 1번 정유진(29, PM) 확정. 총 10턴.
숨은 니즈(비공개): 인정받고 싶다.

```
1턴 정유진: 어 여기 라떼 맛있다고 소문났대요! 카페 자주 오세요?
사용자: 저도 커피 좋아해서 자주 와요. 여기 어떻게 알고 오셨어요?
▓▓▓░░░░░ 33 (+3) 되묻기로 대화 공을 넘겼어요.

2턴 정유진: 친구 추천으로요! 여기 케이크도 유명해요. 단 거 좋아하세요?
사용자: 네 좋아해요.
▓▓▓░░░░░ 33 (0) 대답만 하고 안 넓혔어요.

3턴 정유진: 저는 디저트 없인 못 살아요 ㅋㅋ. 참, 회사가 근처라 자주 와요. 요즘 프로젝트 마감 때문에 정신없어요.
사용자: 저희 팀은 이번에 대박 프로젝트 따서 완전 잘 나가요 ㅋㅋ.
▓▓░░░░░░ 25 (-8) 상대가 힘든 얘기를 꺼냈는데 자기 자랑으로 받아쳤어요.

4턴 정유진: 아... 그렇구나요. 주말엔 보통 뭐 하세요?
사용자: 저는 운동해요. 유진 님도 하시는 거 있어요?
▓▓░░░░░░ 28 (+3) 식었던 분위기를 되묻기로 조금 되돌렸어요.

5턴 정유진: 저는 요가해요! 근데 요즘 배포 때문에 스트레스가 좀 심해요.
사용자: 저도 요가 관심 있었는데 잘됐다 ㅋㅋ.
▓▓░░░░░░ 28 (0) 요가에는 반응했지만 스트레스 얘기는 그냥 지나갔어요.

6턴 정유진: 맞아요 요가 좋아요! 근데 다이어트 하려고 시작했는데 잘 안돼요 ㅎㅎ.
사용자: 무리한 다이어트보단 꾸준히 하는 게 낫죠. 어떤 운동 좋아해요?
▓▓▓░░░░░ 32 (+4) 공감하고 되물었어요.

7턴 정유진: 맞아요! 참, 아까 그 프로젝트 이번에 팀 성과 인정받아서 좀 뿌듯했어요.
사용자: 오 잘됐네요.
▓▓▓░░░░░ 33 (+1) 축하는 했지만 뭐가 잘됐는지는 안 물었어요.

8턴 정유진: 저 사실 소개팅 오랜만이라 좀 긴장돼요 ㅎㅎ.
사용자: 저도 긴장돼요. 근데 얘기 잘 통해서 편해지고 있어요.
▓▓▓░░░░░ 36 (+3) 자기 개방과 공감이 같이 나왔어요.

9턴 정유진: 다행이다 ㅎㅎ 저도 편해졌어요.
사용자: 저도 좋아요, 유진 님 얘기 더 듣고 싶어요.
▓▓▓░░░░░ 40 (+4) 관심을 직접 표현했어요.

10턴 정유진: 오늘 즐거웠어요! 다음에 또 봬요~
```

최종 호감도 40 → **어색한 헤어짐**.

```md
## 부검 리포트

- 자기 얘기 비율: 46% (전체 13문장 중 6문장)
- 질문 횟수: 3회
- 리액션 횟수: 4회

### 결정적 순간

1. 3턴: "저희 팀은 이번에 대박 프로젝트 따서 완전 잘 나가요 ㅋㅋ" → 정유진이
   마감 스트레스를 나눴는데 자기 자랑으로 받아쳐 대화 주도권을 가져왔어요. 대신:
   "완전 정신없겠다, 요즘 제일 힘든 게 뭐예요?"
2. 5턴: "저도 요가 관심 있었는데 잘됐다 ㅋㅋ" → 정유진이 스트레스가 심하다고
   흘렸는데 취미 얘기만 받고 지나갔어요. 대신: "배포 스트레스면 요즘 많이
   힘들겠다, 괜찮아요?"
3. 7턴: "오 잘됐네요" → 정유진이 성과를 인정받아 뿌듯했다고 직접 말했는데
   되묻지 않아서 대화가 짧게 끝났어요. 대신: "오 진짜요? 어떤 부분에서
   인정받은 거예요?"

### 숨은 니즈

상대의 숨은 니즈는 **인정받고 싶다**였다. 못 알아챘다. 3턴, 5턴, 7턴 세 번 모두
정유진이 일 얘기로 신호를 줬는데 자기 얘기나 짧은 리액션으로만 받았다.

### 다음 훈련 과제

상대가 감정을 담아 말하면(힘들다, 뿌듯하다 등) 그 감정을 한 번 더 물어보기.

### 지난 회차와 비교

지난 회차(8턴, 보통, 술집)는 질문 2회였는데 이번엔 3회로 늘었다. 다만 "니즈를
못 알아챔"은 최근 3회 연속 나왔다. **고질병**으로 표시한다.
```

이 예시는 형식 견본이다. 실제 세션에서는 매번 다른 페르소나와 다른 대화로
진행하고, 위 대사를 그대로 재사용하지 않는다.
