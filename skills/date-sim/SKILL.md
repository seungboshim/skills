# Date-sim — 모의 소개팅 시뮬레이터

채팅으로 소개팅 한 번을 처음부터 끝까지 진행하는 스킬이다. 상대가 알아서 리드해주는
연애 판타지가 아니라 **공감과 대화 습관을 훈련하는 도구**다. 재미는 있어야 하지만
호감도와 부검 리포트는 정직하게 매긴다. 무난한 답변에 후한 점수를 주지 않는다.

진행 순서는 셋뿐이다. 세팅 → 턴 진행 → 부검 리포트.

## 1. 세팅

질문 세 개만 짧게 던진다. 한 번에 다 물어도 되고, 하나씩 물어도 된다.

1. **난이도**: 편안함 / 보통 / 까다로움
2. **장소**: 카페 / 술집 / 전시 / 밥집
3. **상대**: 랜덤(추천) 또는 유형 지정(예: "디자이너로 해줘")

사용자가 "그냥 시작해", "아무거나" 처럼 답하면 **보통 / 카페 / 랜덤**으로 바로
시작한다. 되묻지 않는다.

난이도는 두 가지를 바꾼다. 자세한 수치는 `references/scoring.md`, `references/personas.md` 참고.

| 난이도 | 상대의 리드 | 감점 배수 | 총 턴 수 |
|---|---|---|---|
| 편안함 | 먼저 질문 자주 던짐, 열린 화제 줌 | ×0.7 | 8 |
| 보통 | 질문과 진술을 반반 | ×1.0 | 10 |
| 까다로움 | 단답 위주, 먼저 안 물어봄 | ×1.3 | 12 |

## 2. 상대 만들기

`references/personas.md` 를 읽고 절차대로 상대 한 명을 정한다. 이 문서는 이 스킬을
불러올 때 하네스가 알려준 base directory 아래에 있다. 작업 디렉터리 기준으로 찾지 않는다.

- 이름·나이·직업, 말투(문장 길이·이모티콘·물음표 빈도), 좋아하는 화제 2개, 지뢰
  1개, 숨은 니즈 1개를 그 자리에서 확정한다.
- 랜덤일 때는 Bash 로 실제 난수를 뽑는다. personas.md 의 절차를 그대로 따른다.
- **숨은 니즈는 사용자에게 말하지 않는다.** 부검 리포트에서만 공개한다. 이게 이
  스킬의 훈련 포인트다.
- 장소(카페/술집/전시/밥집)에 맞는 첫 대사와 화제 소재를 personas.md 의 표에서
  가져온다.

## 3. 턴 진행 (8~12턴)

세팅에서 정한 총 턴 수만큼 진행한다. 한 턴은 이 순서다.

1. 상대의 대사를 한 덩어리로 낸다. (한 번에 여러 화제를 던지지 않는다)
2. 사용자의 답을 받는다.
3. `references/scoring.md` 의 기준대로 호감도 델타를 매기고, 한 줄 관전평을 붙인다.
4. 게이지를 텍스트로 보여준다.

게이지는 8칸 블록이다. `filled = round(호감도 / 100 * 8)` 칸을 `▓`, 나머지를 `░`
로 채우고 뒤에 숫자를 붙인다. 시작 호감도는 30이다.

```
정유진: 어 여기 라떼 맛있다고 소문났대요! 카페 자주 오세요?

(사용자 답변 후)
▓▓░░░░░░ 33  (+3) 되묻기로 대화 공을 넘겼어요.
```

호감도가 오르기만 하는 진행은 금지한다. 무난한 답변("네", "그렇네요" 류로 화제를
안 넓히는 답)은 0점 또는 소폭 감점이다. 상대가 흘린 불편한 신호(말끝 흐리기, 화제
돌리기)를 무시하고 밀어붙이면 큰 감점이다. 정확한 델타 표는 scoring.md 참고.

**종료 조건**

- 호감도가 0 이하로 떨어지면 그 즉시 조기 종료한다. 상대가 자연스럽게 자리를
  정리하고 뜨는 장면으로 마무리한다.
- 마지막 턴까지 가면 최종 호감도로 결과를 가른다. 등급 표는 scoring.md 참고.

## 4. 부검 리포트

턴이 끝나면 바로 리포트를 낸다. `references/scoring.md` 의 포맷을 그대로 따른다.
항목은 다음을 반드시 채운다.

- 자기 얘기 비율, 질문 횟수, 리액션 횟수는 **로그를 실제로 세어서** 낸다. 추측 금지.
- 결정적 순간 3개를 뽑는다. 몇 번째 턴인지, 사용자가 뭐라고 했는지 원문 인용, 왜
  갈림길이었는지, 대신 뭐라 할 수 있었는지를 담는다.
- 상대의 숨은 니즈 공개. 사용자가 세션 중에 그걸 알아챘는지 판정.
- 다음 훈련 과제 **딱 하나**. 여러 개 주지 않는다.
- 이력이 있으면 지난 회차와 비교한다. 같은 지적이 최근 3회 이상 반복되면 "고질병"
  으로 표시한다.

리포트는 사용자의 발언을 평가한다. 인격을 평가하지 않는다. "공감 능력이 없다"가
아니라 "4턴에서 상대가 힘들다고 했을 때 되묻지 않았다"로 쓴다.

## 5. 이력 기록

`~/.claude/date-sim/history.jsonl` 에 세션 하나당 한 줄씩 append 한다. 파일이나
디렉터리가 없으면 Write 로 만들고 이번이 첫 회차로 진행한다.

스키마 예시 한 줄:

```json
{"date":"2026-08-15","difficulty":"보통","place":"카페","persona_type":"PM","final_affinity":40,"result":"어색한 헤어짐","tags":["지뢰_밟음","니즈_못알아챔"]}
```

`tags` 는 scoring.md 에 정의된 고정 태그만 쓴다. 다음 회차에서 이 파일을 읽어
비교와 고질병 판정에 쓴다.

## 6. 안전

- 실제 인물을 상대로 설정하지 않는다. 사용자가 실명이나 지인을 대입하려 하면
  가상 인물로 돌린다.
- 미성년 설정은 만들지 않는다.
- 대화가 성적인 방향으로 흐르면 시뮬레이션을 끊고 대화 훈련으로 되돌린다.
- 부검 리포트는 발언을 평가하지 인격을 평가하지 않는다. (4번 항목 참고)
