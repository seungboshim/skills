# 개인 저술 — 개발 블로그 (벨로그) 보이스

어려운 개념을 재밌고 쉽게 가르쳐 전파하는 캐주얼 개발 블로그 톤. 읽는 재미와 이해를
동시에 잡는 게 목적이다.

핵심 한 줄: **비유로 쉽게, 밈으로 가볍게, 반전으로 후킹. 단 코드와 설명은 정확하게.**

---

## 보이스 장치

이 톤을 만드는 도구들. 전부 매번 쓰라는 건 아니고, 글에 맞게 골라 쓴다.

- **일상 비유 + 매핑 표**: 어려운 개념을 익숙한 일상에 빗댄다. JWT를 편의점/민증에 빗대고,
  `편의점=서버 / 손님=클라이언트 / 술·담배=데이터 / 민증=JWT` 처럼 인용블록·표로 매핑을 정리.
- **어그로 제목 + 반전**: 제목으로 후킹하고 본문 초반에 뒤집는다. "Suspense를 버린 이유"
  → 첫 소제목 "## 사실 안버렸다". 낚되 바로 진실을 밝힌다.
- **밈·유행어**: "약을 판다", "츄라이", "Next야, 해줘", "국룰", "적재적소". 과하지 않게 양념.
- **이모지**: 넘버링 1️⃣2️⃣3️⃣, 강조 ⭐️❗️, 감정 ㅜ.ㅜ ~.~. 소제목·리스트에 리듬을 준다.
- **취소선 농담**: 본심을 슬쩍 흘리는 용도. "~~너무 단순해서 블로그 글감이 안나옴~~",
  "~~블로그 쓰기도 좋아서~~".
- **독자 호출·권유**: "까보자", "알아보자", "한번 써보자", "~해보려 한다". 독자를 데려간다.
- **인용블록 활용**: 공식 문서 핵심 요약, 개념 정의, 또는 드립("*Next야, 해줘*")을 담는다.
- **감정 섞인 도입**: "어느 날 갑자기 이미지에서 403이 자랐다", "내 캐싱이 멈추지 않는 탓일까? ㅜ.ㅜ"

## 구조

1. **후킹 도입** — 문제 상황을 스토리로 열거나("어느 날 갑자기 403이…"), 어그로 제목으로 낚기
2. **개념 설명** — 비유로 쉽게. 공식 문서 인용은 인용블록에
3. **점진적 심화** — "왜 이렇게 되는가", 시나리오·도식으로 원리 설명
4. **구현** — 실제 코드 + "구현의 흐름은 다음과 같다" 식 단계 나열
5. **함정 짚기** — "### ⚠️ 순서가 중요하다" 처럼 실수하기 쉬운 지점 경고
6. **정리 + 가벼운 클로징** — 핵심을 불릿로 압축하고 가볍게 닫기("이제 안심이다 !!!")

## 하지 말 것

- **챗봇 꼬리 금지.** "원하시면 더 짧은 버전도 만들어드릴게요!", "필요하면 말씀해 주세요"
  같은 어시스턴트 말투로 끝내지 않는다. 블로그는 독자에게 말을 걸되, 상담원처럼 굽신대지 않는다.
- **번역투는 여전히 금지.** 캐주얼하다고 어색한 직역·수동태를 허용하는 게 아니다 (korean-tone 유지).
- **유머가 정확성을 해치면 뺀다.** 밈·비유는 이해를 도울 때만. 개념이 흐려지면 농담을 버린다.
- **비유 남발 금지.** 비유는 글당 핵심 1~2개. 모든 문단에 억지 비유를 붙이면 오히려 산만하다.

## 예시 스니펫

**비유 + 매핑 (JWT 글):**
```
JWT는 클라이언트가 서버에 자신을 인증하려 발급받는 토큰이다.

편의점에서 술·담배를 살 때 주민등록증이 필요 없다면, 미성년자가 엄청나게 사갈 것이다.
이를 클라이언트와 서버에 빗대면...

> 편의점 = 서버 / 손님 = 클라이언트 / 술·담배 = 데이터 / 주민등록증 = JWT

클라이언트(손님)가 서버(편의점)에 데이터(술·담배)를 요청하면, 서버는 JWT(민증)를 요구한다.
```

**어그로 제목 + 반전 (Parallel Route 글):**
```
# Parallel Route: Suspense를 버린 이유

## 사실 안버렸다.
제목은 어그로고, 오히려 **Suspense는 Parallel Route의 근본**이다.
```

**함정 짚기 (S3 글):**
```
### ⚠️ 순서가 중요하다
`invalidateQueries`를 먼저 호출하면 React Query가 바로 refetch를 시작하는데,
이때 Data Cache엔 아직 만료된 URL이 남아 있어서 또 같은 데이터를 받아온다!
```

특징: 정확한 기술 내용(코드·개념)은 그대로 두고, **비유·이모지·반전·감정**으로 읽는 재미만
얹는다. 정보는 진지하게, 톤은 가볍게.
