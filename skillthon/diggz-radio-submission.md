# Mood Compiler — 코드 상태를 인디 플레이리스트로 컴파일한다

## 한 줄 소개

지금 하는 개발 작업과 기분을 읽고, 아직 덜 알려진 실제 트랙을 디깅해 한 번 클릭으로 재생되는
30~90분짜리 코딩 라디오를 만드는 스킬.

## 제출 설명 본문

“집중 음악 틀어줘”라고 하면 유명한 로파이 플레이리스트 링크가 돌아옵니다. Mood Compiler는
음악 취향보다 먼저 **지금 코딩이 어떤 상태인지** 읽습니다. 설계 중인지, 같은 테스트가 깨지는지,
파일 30개를 기계적으로 고치는지에 따라 `deep-focus`, `debug-loop`, `mechanical` 장면을 잡고,
음악이 나를 밀어야 하는지·붙잡아야 하는지·식혀야 하는지를 따로 판단합니다.

그다음 실제 YouTube 트랙을 디깅합니다. 기본 저점은 곡 150만 조회, 채널 500만 조회입니다.
같은 아티스트는 반복하지 않고, 70% 정합·20% 인접·10% 와일드카드로 섞습니다. 곡을 점수순으로
나열하지 않고 `entry → lock → turn → landing` 역할을 부여해 30~90분짜리 에너지 곡선으로
편집합니다. “좋은 곡이라서”가 아니라 **왜 지금 이 위치에 놓였는지**를 곡마다 설명합니다.

결과는 대화 속 링크 목록이 아니라 Diggz Radio 화면입니다. 공식 YouTube 플레이어, 이전·다음,
곡별 배치 이유, 조회수, 에너지 곡선, YouTube Music 핸드오프가 한 화면에 있습니다. 화면이 열려도
소리는 나지 않고 사용자가 `세션 시작`을 눌러야 재생됩니다.

전용 YouTube Music 공식 API가 있다고 가정하지 않았습니다. 비공식 내부 API, 쿠키 복사,
스크래핑, 다운로드 없이 공식 YouTube IFrame Player와 Data API만 씁니다. API 키가 없으면 웹
검색으로 실제 영상 ID를 검증하고, 그마저 없으면 사용자의 인디 링크 2~3개를 씨앗으로 받습니다.
검증할 수 없는 곡·영상 ID·조회수는 만들지 않습니다.

## 심사 기준별 근거

- **기상천외함:** git 작업 상태를 음악의 장면·에너지 곡선으로 번역하는 “기분 추천기”가 아닌 “코딩 세션 컴파일러”.
- **유용함:** 디버깅 과열, 반복 작업 졸림, 배포 직전 긴장처럼 개발 중 실제 상태를 즉시 조절한다.
- **완성도:** 작업 판독 → 공식 API 디깅 → 저점 필터 → 흐름 편집 → 로컬 플레이어까지 한 번에 이어진다.
- **재사용성:** 특정 저장소나 장르에 묶이지 않고 Python 표준 라이브러리와 브라우저만으로 동작한다.
- **신뢰성:** 가짜 트랙 금지, 자동재생 금지, HTML 인젝션 방어, 중복 아티스트 거부, 쿠키·비공식 API 금지.
